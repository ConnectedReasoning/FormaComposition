Here is a sonata in G minor generated by a rules-based composition program I wrote with AI assistance. 

I’m an amateur musician. I’ve released ambient music for a few years as Connected Reasoning, and I’ve read a fair amount of theory and form, but I wouldn’t call myself proficient. I’d like feedback on the music and on the form.

The program began as a short hand-written script that picked random notes from a scale, inspired by Brian Eno’s generative methods. I had read Piston’s Harmony and Kostka, Payne and Almén’s Tonal Harmony years earlier, and wondered whether I could combine the two ideas. AI helped write much of the current code to implement the more complex music theory processing. 

The program reads a JSON file describing a music piece, the key, the mode, the sections. The application engine uses rules from music theory to constrain the chords and cadences. Random choice picks the notes within those constraints. 

As the pieces got more and more listenable I became more ambitious adding styles and genres beyond ambient. 

Here is how sonata in g minor was created. 
- I asked Claude to generate a configuration file for a sonata.
- Claude chose the form, key plan and rhythms. There is no specific source or quoted work.
- I ran the JSON file through FormaComposition to generate the midi file. 
- I imported the midi file into Logic Pro using the Arturia Piano V3 instrument.
- Logic Pro rendered an MP3 which I combined with a screenshot of Logic Pro as the YouTube visual.

All of this is available in the links below including the links to the GitHub repository and Youtube. 

I’m posting to see how people respond to this workflow and I would value feedback on the music. I have read the rules regarding AI use in this subreddit and understand that this post may land in a gray area.
